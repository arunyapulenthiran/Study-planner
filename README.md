StudyFlow

A responsive, interactive study-planning web app designed to help students organize subjects, tasks, study sessions, and focused study time in one place.

Live Demo: https://arunyapulenthiran.github.io/Study-planner/

Repository: https://github.com/arunyapulenthiran/study-planner

⸻

About

StudyFlow was created as a practical web application for students who want a simple way to organize their study routine.

Users can create their own subjects, manage tasks, schedule study sessions, and use a built-in focus timer. Study data is stored locally in the user’s browser, allowing the app to work without requiring an account or backend.

⸻

Features

* Add and manage personal subjects
* Create, complete, and delete study tasks
* Plan study sessions across a weekly schedule
* Choose a subject for focused study sessions
* 25-minute focus timer
* Dashboard statistics
* Today’s scheduled study sessions
* Responsive desktop and mobile layout
* Local browser storage for user data

How It Works

Subjects

Users can add the subjects they are currently studying and manage them from the Subjects section.

Tasks

Study tasks can be created, marked as completed, and removed when no longer needed.

Schedule

Users can organize study sessions throughout the week by selecting a subject, day, time, and duration.

Focus Session

Users can select a subject and start a 25-minute focused study session.

Local Storage

StudyFlow uses the browser’s LocalStorage API to save subjects, tasks, schedules, and focus preferences locally on the user’s device.

No account is required to use the core features.

⸻

Design

StudyFlow uses a soft pastel visual system with a centered layout designed to create a calm and focused study environment.

The interface is responsive and adapts to smaller screens for mobile use.
